# EG2140 — course material

This repository holds everything you read and run in EG2140: the notebooks from the
lecturecises, the follow-along guides, the lab instructions, the project briefs and the
datasets. It is public, so you can browse it before the course starts and long after it ends.

**Canvas is the hub.** The schedule, the sessions, the quizzes and the hand-ins live there.
This repository is where the work lives.

## What is where

| Folder | What it holds |
|---|---|
| `notebooks/` | The session notebooks — LC01's Svedala warm-up (runs in Colab, nothing to install) and LC06–LC13 |
| `guides/` | The follow-along guides for LC02–LC05: environments, code quality, git, testing |
| `labs/` | Lab 1–9 instructions, plus the files the labs hand you (`awful_screener.py`, `bisect-practice.zip`, the review checklist) |
| `data/` | The Svedala grid: CSVs, the CIM-XML export, and the year of hourly data used from Module 2 onwards |
| `project/` | Period 2: the four industry challenges, the plan template and the opposition pack |

Your own work does not go here. You get a personal repository, `p1-workbook-<your username>`,
after the day-1 survey, and your project group gets one in Period 2.

## Asking questions

Use [Discussions](https://github.com/KTH-EG2140/course-material/discussions). For lab work the
order is: your lab partner, then your pod, then Discussions, then the sessions with the teaching
assistant. A question asked in Discussions helps fifteen people; the same question asked by mail
helps one.

## One rule worth repeating

Period 1 is the AI-free phase. The labs and the quizzes train the judgment you will need when the
agent arrives in Period 2 — the rules are on the Canvas page "Rules for use of generative AI",
and everything here assumes you have read them.
